📋 How to set up the Power Automate webhook (10 min)

  1. Go to make.powerautomate.com and sign in with your Walmart account.
  2. Click + Create → Instant cloud flow, choose “When an HTTP request is received” as the trigger.
  3. Inside the trigger, click “Use sample payload to generate schema” and paste the JSON below, then click Done.
  4. Add action: “Post message in a chat or channel” → Team: Dispo, Channel: RE Dispo. Include the dynamic fields in the message body.
  5. Add action: “Send an email (V2)” → To: realestatedispositions@walmart.com.
  6. (Optional) Add action: “Create item” → SharePoint → your ICSC LOI list.
  7. Click Save, then copy the HTTP POST URL from the trigger card and paste it in the field above.

Sample payload to paste in step 3:

{
  "submittedAt": "2026-05-17T12:00:00Z",
  "property": "Baton Rouge, LA",
  "propertyId": "384",
  "loiType": "Building Lease",
  "firstName": "John",
  "lastName": "Doe",
  "email": "john@example.com",
  "phone": "555-123-4567",
  "company": "Acme Corp",
  "companyAddress": "123 Main St"
